ДНЕВНИК Рури

МОЗГ и личность

API-ключи шифруются с помощью Android Keystore и не включаются в обычный экспорт памяти. В core/config.json остаются только настройки моделей. Рури сначала обращается к выбранной модели, затем пробует остальные настроенные модели.

Мониторинг уведомлений телефона работает только после твоего разрешения Android. Содержимое уведомлений будет записываться в локальный журнал памяти.

Доступ к статистике использования приложений позволяет Рури локально определять название активного приложения. Текст экрана и вводимые данные этим разрешением не читаются.

Доступ к статистике приложений не проверен.

ПОЛКА файлов

Локальные заметки и материалы, которые Рури может учитывать в следующих циклах мышления. Файлы остаются на телефоне.

ПОИСК в сети

Рури ищет открытые веб-страницы через DuckDuckGo. Нажми на результат, чтобы открыть страницу в браузере телефона.
